| **想完成的一個任務** | 將一段非結構化的活動或講座宣傳文案，精準萃取為 7 個結構化欄位（活動名稱、活動類型、時間地點、適用對象名額、核心亮點議程、報名與待辦事項、待確認缺失資訊），並精確指出缺少之關鍵資訊；嚴格遵守「只依原文」之事實邊界，不捏造任何未提及的人物、日期、地點或規則。 |

| **資訊不足如何處理** | 任務規則（`INSTRUCTIONS`）中明確要求：<br>1. 若時間或地點未提及，填入「原文未提及時間或地點」。<br>2. 若對象未限定，填入「原文未限定對象」或「原文未提及」。<br>3. `key_highlights` 與 `action_items` 原文無對應內容時回傳空清單 `[]`。<br>4. 設置專門的 `missing_info` 欄位列出缺失的關鍵要素（如缺少時間、地點、報名連結等）；若資訊完整則為空清單。模型不得自行補造或臆測任何事實。 |

| **結構化輸出路線** | **Pydantic 路線**。<br>**選擇理由**：相較於手寫 JSON Schema 字典，使用 Pydantic `BaseModel` 定義資料契約更具 Pythonic 特性，享有靜態語法檢查、IDE 自動補全與強型別驗證。搭配 OpenAI SDK 的 `client.responses.parse(text_format=ProjectResult)`，SDK 能自動將 Pydantic 模型轉為嚴格模式的 JSON Schema (`strict=True`, `extra="forbid"`)，並在底層自動反序列化與驗證，使程式結構更簡潔、穩健且維護性高。 |
| **相較教師範例的個人設計** | 1. **選題與業務場景創新**：教師範例為通用的「課堂筆記重點整理器（3欄：title, summary, key_points）」，本專題針對校園資訊碎片化痛點，設計為專門的「校園活動與講座資訊萃取器（7欄）」。<br>2. **欄位合約全面拓展**：不使用通用摘要，而是精確定義出 `event_title`、`event_type`、`time_and_location`、`target_audience`、`key_highlights`、`action_items`、`missing_info` 等 7 個欄位，能直接對接學生個人行事曆與待辦規劃。<br>3. **明確的主動防幻覺與缺失偵測**：設計了 `missing_info` 清單欄位，讓 LLM 在面對簡短或模糊公告時，明確指出「缺少什麼」，而非編造資訊充數。<br>4. **UI 與操作體驗優化**：<br>   - 設計雙欄資訊卡（時間地點與資格），搭配亮點清單、待辦清單與黃色警示的缺失區塊。<br>   - 提供「快速載入測試範例」下拉選單（包含完整職涯講座與缺失快訊），方便評分與展示時一鍵載入測試。 |

## 二、輸出欄位契約

外層為符合 `ProjectResult` 之嚴格 JSON 物件，`model_config = ConfigDict(extra="forbid", strict=True)`。全部欄位均為必填，各欄位型別僅使用 `str` 或 `list[str]`，並在程式端逐一檢查禁止全空白字串。

| 欄位名稱 | 型別／限制 | 用途 | 畫面標籤 | 如何查原文 |
|---|---|---|---|---|
| `event_title` | `str`；必填、非空白字串 | 活動名稱或主題短標題 | 活動名稱 | 核對是否符合宣傳文案之主標題或活動主題，未摻雜無關字詞。 |
| `event_type` | `str`；必填、非空白字串 | 活動分類（例如：職涯講座、工作坊、社團迎新、企業參訪） | 活動類型 | 比對宣傳文案的性質敘述，確認歸類精確。 |
| `time_and_location` | `str`；必填、非空白字串 | 舉辦時間（含日期/時段）與地點（含教室/線上連結）之整合說明；未提供時填「原文未提及時間或地點」 | 舉辦時間與地點 | 逐字核對原文中的日期、時間與地點；確認沒有憑空生出具體日程。 |
| `target_audience` | `str`；必填、非空白字串 | 適用對象、參與資格限制與名額上限；未說明時註明「原文未限定對象」或「原文未提及」 | 適用對象與名額資格 | 檢查是否有科系限制、身分限制或實體/線上人數限制。 |
| `key_highlights` | `list[str]`；必填；可為 `[]`，若有元素須為非空白字串 | 活動亮點、議程重點或主講人專案內容清單 | 核心亮點與議程 | 逐項回查原文重點或大綱清單，確認未加入未發生的議程。 |
| `action_items` | `list[str]`；必填；可為 `[]`，若有元素須為非空白字串 | 報名方式、表單連結、截止時間、費用或參與者需自備物品清單 | 報名方式與待辦事項 | 核對報名網址、截止期限、費用與自備筆電等具體行動要求。 |
| `missing_info` | `list[str]`；必填；可為 `[]`，若有元素須為非空白字串 | 文案中模糊、缺漏或待確認之關鍵活動資訊清單；資訊完整時為空清單 | 待確認與缺失資訊 | 檢查原文是否漏掉關鍵要素（如缺時間、缺地點、缺費用、缺聯絡人），模型是否精準抓出缺失而非臆測。 |
